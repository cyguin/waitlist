# @cyguin/waitlist Demo

Demo application showcasing [@cyguin/waitlist](https://github.com/cyguin/waitlist) — an email waitlist with position tracking for Next.js.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the waitlist form in action.

## What This Demonstrates

- Waitlist join form with email validation
- Position/count tracking
- Admin panel for managing entries
- SQLite-backed persistence
